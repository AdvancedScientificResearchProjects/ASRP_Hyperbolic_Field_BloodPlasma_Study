## Навигация и структура

С чего начинать, зависит от вопроса:

| Если нужно | Читать |
|---|---|
| Что за исследование и как оно проводилось | [Исследование](STUDY.ru.md), затем `original_research/reports/experiment_protocol_ru.md` |
| Выдерживают ли утверждения проверку | [Свидетельства](EVIDENCE.ru.md), у каждой строки путь к источнику |
| Числа как заявлены и как их читать | [Результаты](RESULTS.ru.md) |
| Фотографии и подсчёты | [Данные и фотографии](DATA.ru.md), затем `original_research/data/` |
| Код анализа и четыре датированных отчёта | [Методы анализа](METHODS.ru.md), затем `original_research/scripts/` и `original_research/reports/` |
| Патент, регистрация, статья | [Патент, регистрация, публикация](PUBLICATIONS.ru.md) |
| Что не решено | [Открытые вопросы](OPEN.ru.md) |

В репозитории три части. `original_research/` содержит всё, что дал эксперимент (данные, код, результаты, отчёты, графики). `ADVANCED_SCIENTIFIC_RESEARCH_PROJECTS/` — зеркало хаба программы: README программы и документы задач. Оно не идентично корневому README по байтам (расходящаяся копия, <!--n:mirror_files-->47<!--/n--> файла), поэтому корень и зеркало могут противоречить друг другу. `OSF_PREREGISTRATION.md` хранит текст регистрации. Главная страница и `guide/` добавлены 2026-11-19; ни один существующий файл не перемещён, не изменён и не удалён, а прежний README сохранён байт в байт в [`archive/`](../archive/README_2026-11-19_pre-showcase.md).

```
│   ├── results/                            # 47 файлов результатов LLM в 48 папках прогонов

│   ├── scripts/                            # 22 файла Python: llm_analysis/, cv_analysis/

│   ├── charts/                             # 3 сводных графика + 11 PNG Mermaid
│   ├── en/                                 # английский документационный хаб
│   └── ru/                                 # русский документационный хаб
└── ADVANCED_SCIENTIFIC_RESEARCH_PROJECTS/  # зеркало хаба программы: README + 6 документов задач (47 файла)
```

## Отчёты и документы задач

Четыре датированных отчёта лежат в `original_research/reports/` (у каждого файл на английском и на русском) и перечислены со ссылками на странице [Методы анализа](METHODS.ru.md#отчёты). Документы задач (`ISSUE_1_UPDATED.md` ... `ISSUE_8_UPDATED.md`, <!--n:issue_docs_ru-->6 документов<!--/n-->) содержат протокол (задача 3), хаб программы (задача 2), биохимический план (задача 5), систему съёмки (задача 6) и план публикации (задача 8); они в зеркальной папке `ADVANCED_SCIENTIFIC_RESEARCH_PROJECTS/Hyperbolic_Field_BloodPlasma_Study/`.
