## Ethics and security

The study works with blood plasma from human donors. The repository holds per-donor logs (blood group, minute-level session times), scanned protocol PDFs with embedded photographs, and EXIF metadata. **These pages therefore carry aggregates only:** no donor is described individually, and donors appear only as numbers. Informed consent and donor screening are specified in the protocol issue (issue 3), but **no consent artefact is in the repository** and the protocol summary mentions donors on antibiotics (see [Open questions](OPEN.md)). Work with the raw donor material should follow the classification below.

### Data classification

| Level | Access | Marking | Description |
|---|---|---|---|
| PUBLIC | Open | GREEN | General information |
| RESEARCH | Team Only | YELLOW | Research data |
| RESTRICTED | Core Team | RED | Sensitive analysis |
| INTERNAL | Director Only | BLACK | Director-level review only |

The per-donor material (`original_research/data/`) should be treated as RESTRICTED. The repository is public, so what it holds is visible to every reader. A review of the donor logs, the PDFs and the per-photo data is needed, and the git history needs a check as well; this restructuring did not change or remove any data file.

### Claims and wording

A patent application is an IP claim, not validation of the study. Results here are preliminary and hypothesis-generating (see [Evidence](EVIDENCE.md)). Nothing here is a clinical result, and no page makes a medical claim.
